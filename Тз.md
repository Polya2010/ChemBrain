# ChemBrain: Интерактивная система изучения химии

## Основные функциональные требования

### 1) Изучение Таблицы Менделеева
- Интерактивное отображение химических элементов
- Свойства и характеристики каждого элемента
- Поиск элементов по названию и характеристике
- Распределение элементов по периодам и группам
- **Интерактивное отображение** химических элементов по координатам из `element_positions.json`
- **Цветовое кодирование** элементов по 9 категориям из `color_categories.json`
- **Детальная информация** по каждому элементу:
  - Основные свойства (символ, название, атомный номер, масса)
  - Физико-химические характеристики (температуры плавления/кипения, плотность, электроотрицательность)
  - Исторические данные (год открытия, первооткрыватель)
  - Интересные факты и области применения из `element_additional.json`
- **Поиск элементов** по названию, символу или атомному номеру
- **Отображение случайного элемента** для обучения

### 2) Тестирующая система
- Прохождение викторин и тестов
- Система подсчета баллов
- Разделы: элементы, соединения, реакции
- **Прохождение викторин** с вопросами из 5 JSON-файлов:
  1. `quiz_questions.json` - основные вопросы
  2. `basic_questions.json` - фундаментальные вопросы
  3. `supplementary_questions.json` - дополнительные вопросы
  4. `element_quiz_questions.json` - вопросы об элементах
  5. `extra_questions.json` - расширенная база вопросов
- **Фильтрация вопросов** по 4 категориям и 3 уровням сложности

**Детализация системы тестирования:**

**Доступные модули тестирования:**
1. **«Элементарный ликбез» (Новичок)** - 100-150 вопросов на знание символов элементов, названий, порядковых номеров, простейших свойств
2. **«Свойства и Закономерности» (Специалист)** - 200-250 вопросов на понимание периодических законов, электроотрицательности, атомных радиусов
3. **«Реакции и Соединения» (Эксперт)** - 150-200 вопросов и задач на составление уравнений реакций, номенклатуру соединений
4. **«Случайный вызов»** - вопросы выбираются случайно из всех модулей
**Доступные категории вопросов:**
1. **«Элементы»** - знание символов, названий, атомных номеров
2. **«Свойства»** - физико-химические характеристики элементов
3. **«История»** - открытие элементов и исторические факты
4. **«Применение»** - практическое использование элементов

**Система сложности и баллов:**
- **Уровень сложности 1 (Легкий):** 1 балл за правильный ответ
- **Уровень сложности 2 (Средний):** 3 балла за правильный ответ  
- **Уровень сложности 3 (Сложный):** 5 баллов за правильный ответ
- Каждая викторина состоит из 10 вопросов со смешанной сложностью
- **Уровень сложности 1 (Легкий):** 5 баллов за правильный ответ
- **Уровень сложности 2 (Средний):** 7 баллов за правильный ответ
- **Уровень сложности 3 (Сложный):** 10 баллов за правильный ответ
- **Каждая викторина** состоит из 5-10 вопросов на выбор пользователя

### 3) Управление прогрессом
- Отслеживание уровня пользователя
- Система достижений
- История пройденных викторин
- Статистика обучения
- **Отслеживание уровня пользователя** от 1 до 50
- **Система достижений** с 5 базовыми и дополнительными достижениями
- **История пройденных викторин** с детальной статистикой
- **Система серий правильных ответов** (streak system)

**Система уровней:**
- Уровень повышается за счет накопления Опыта (XP)
- Опыт начисляется за: прохождение викторин, правильные ответы, серии правильных ответов, получение достижений
- Опыт начисляется за правильные ответы (10 XP за каждый)
- Формула перехода на следующий уровень: Уровень N → Уровень N+1 требует N * 1000 XP
- Всего 50 уровней, где 50-й - уровень «Дмитрий Менделеев»

**Система достижений:**
- **«Первые шаги»** - Пройти первую викторину
- **«Серия удач»** - Ответить правильно на 10 вопросов подряд
- **«Неудержимый»** - Ответить правильно на 50 вопросов подряд
- **«Эрудит»** - Набрать 100% правильных ответов в викторине
**Система достижений (реализованные):**
- **«Начало пути»** - Пройти первую викторину
- **«Последовательность успеха»** - Ответить правильно на 10 вопросов подряд
- **«Знаток химии»** - Набрать 100% правильных ответов в викторине
- **«Молниеносный ответ»** - Пройти викторину менее чем за 2 минуты
- **«Современный Менделеев»** - Достичь 10 уровня

**Система достижений (планируемые):**
- **«Знаток металлов»** - Правильно ответить на все вопросы о металлах
- **«Мастер реакций»** - Решить все задачи в модуле «Реакции и Соединения»
- **«Скорострел»** - Пройти викторину менее чем за 2 минуты
- **«Ночной ученый»** - Решить викторину после 23:00
- **«Коллекционер»** - Получить 10 различных достижений
- **«Менделеев нашего времени»** - Достичь 50-го уровня

### 4) Работа с данными
- Экспорт статистики и результатов обучения в CSV
- Импорт/экспорт наборов вопросов для преподавателей
- Сохранение прогресса
- Резервное копирование данных

**Формат экспорта результатов обучения:**
CSV-файл со столбцами: 
- `timestamp` - Дата и время завершения викторины
- `quiz_module` - Название пройденного модуля
- `total_questions` - Общее количество вопросов
- `correct_answers` - Количество правильных ответов
- `score` - Набранные баллы
- `time_spent_seconds` - Затраченное время в секундах
- `xp_earned` - Полученный опыт
- `achievements_unlocked` - Список полученных достижений
- **Автоматическое сохранение прогресса** в SQLite базе данных
- **Резервное копирование данных** пользователей в `user_progress_data.json`
- **Импорт данных элементов** из JSON файлов при первом запуске
- **Экспорт статистики** через интерфейс профиля

**Формат данных в базе:**
- Все данные хранятся в SQLite с полной историей викторин
- Резервные копии в JSON для удобства миграции
- Аватары пользователей хранятся в папке `data/avatars/`

### 5) База данных

| **quizzes** | quiz_id, quiz_name, difficulty |
| **questions** | question_id, quiz_id, question_text, question_type, correct_answer, wrong_answers, difficulty, explanation |
| **users** | user_id, username, current_level, total_xp, creation_date |
| **user_progress** | progress_id, user_id, quiz_id, date_completed, score, xp_earned |
| **achievements** | achievement_id, name, description, icon_path |
| **user_achievements** | user_id, achievement_id, date_unlocked |
| Таблица | Назначение | Основные поля |
|---------|------------|---------------|
| **users** | Данные пользователей | `user_id`, `username`, `user_level`, `accumulated_experience`, `registration_date`, `correct_streak`, `maximum_streak`, `avatar_filename` |
| **achievements** | Каталог достижений | `achievement_id`, `name`, `description`, `points` |
| **user_achievements** | Полученные достижения | `user_achievement_id`, `user_id`, `achievement_id`, `unlock_date` |
| **quiz_results** | Результаты викторин | `result_id`, `user_id`, `quiz_title`, `total_questions`, `correct_responses`, `final_score`, `maximum_score`, `time_elapsed_seconds`, `experience_earned`, `level_increased`, `completed_date` |
| **elements** | Химические элементы | `atomic_number`, `symbol`, `name`, `atomic_weight`, `element_group`, `period`, `category`, `electron_config`, `electronegativity`, `melting_point`, `boiling_point`, `density`, `discovery_year`, `discoverer`, `description` |
| **element_facts** | Факты об элементах | `fact_id`, `atomic_number`, `fact_text` |
| **element_uses** | Применение элементов | `use_id`, `atomic_number`, `use_text` |
| **questions** | Вопросы викторин | `question_id`, `question_text`, `question_type`, `correct_answer`, `explanation`, `difficulty`, `points` |
| **question_options** | Варианты ответов | `option_id`, `question_id`, `option_text`, `is_correct` |
| **question_categories** | Категории вопросов | `category_id`, `question_id`, `category_name` |

**Всего: 10 таблиц, 8 индексов для оптимизации**

## Архитектура и дизайн

### Основные модули
- **Главное окно**: основной интерфейс, меню, панель инструментов
- **Модуль Таблицы Менделеева**: отображение и взаимодействие с элементами
- **Модуль тестирования**: создание и проведение викторин и тестов, проверка ответов
- **Модуль прогресса**: отслеживание достижений пользователя и уровня его знаний
- **Модуль данных**: хранение информации об элементаи, пользователях, вопросах
- **Модуль файлов**: реализует функции импорта и экспорта данных

### Структура меню и панели инструментов

#### Меню приложения
- **Файл**
  - Экспорт результатов
  - Импорт наборов вопросов
  - Выход
- **Обучение**
  - Таблица Менделеева
  - Викторины
  - Тренировка
- **Прогресс**
  - Статистика
  - Достижения
  - История обучения
- **Справка**
  - О программе
  - Правила

#### Горячие клавиши
- `Ctrl + M` - Таблица Менделеева
- `Ctrl + W` - Старт викторины
- `Ctrl + S` - Статистика
- `Ctrl + E` - Экспорт данных
- `Ctrl + F` - Поиск элементов
- **Главное окно (`ChemistryEducationApp`)** - основной интерфейс с вкладками
- **Модуль Таблицы Менделеева (`PeriodicTableDisplay`)** - отображение и взаимодействие с элементами
- **Модуль тестирования (`QuizInteractionPanel`)** - создание и проведение викторин, проверка ответов
- **Модуль прогресса (`AccountManager`, `UserProfileInterface`)** - отслеживание достижений и уровня знаний
- **Модуль данных (`DatabaseManager`)** - хранение информации в SQLite базе
- **Модуль аутентификации (`LoginDialog`)** - регистрация и вход пользователей

### Структура интерфейса

1. **📊 Таблица элементов** - интерактивная периодическая таблица
2. **🧪 Химические викторины** - система тестирования знаний
3. **👤 Профиль пользователя** - статистика и достижения

### Горячие клавиши (реализованные)
- `Ctrl + M` - Перейти к Таблице Менделеева
- `Ctrl + W` - Запустить викторину

- `Ctrl + R` - Показать случайный элемент
- `F11` - Полноэкранный режим
- `F1` - Справка по горячим клавишам
- `Ctrl + Q` - Выход из приложения

### Архитектурные особенности
- **Многослойная архитектура** с разделением данных, логики и представления
