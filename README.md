# ChemBrain
Помощник по химии на PyQt

## Основные функциональные требования

### 1) Изучение Таблицы Менделеева
- Интерактивное отображение химических элементов
- Свойства и характеристики каждого элемента
- Поиск элементов по названию и характеристике
- Распределение элементов по периодам и группам

### 2) Тестирующая система
- Прохождение викторин и тестов
- Система подсчета баллов
- Разделы: элементы, соединения, реакции

### 3) Управление прогрессом
- Отслеживание уровня пользователя
- Система достижений
- История пройденных викторин
- Статистика обучения

### 4) Работа с данными
- Импорт данных об элементах из csv файлов
- Экспорт результатов обучения
- Сохранение прогресса
- Резервное копирование данных

## Архитектура и дизайн

### Основные модули
- **Главное окно**: основной интерфейс, меню, панель инструментов
- **Модуль Таблицы Менделеева**: отображение и взаимодействие с элементами
- **Модуль тестирования**: создание и проведение викторин и тестов, проверка ответов
- **Модуль прогресса**: отслеживание достижений пользователя и уровня его знаний
- **Модуль данных**: хранение информации об элементах, пользователях, вопросах
- **Модуль файлов**: реализует функции импорта и экспорта данных

### Структура меню и панели инструментов

### Меню приложения
- **Файл**
  - Импорт данных
  - Экспорт результатов

- **Обучение**
  - Таблица Менделеева
  - Викторины
  - Тренировка
- **Прогресс**
  - Статистика
  - Достижения
  - История обучения
- **Справка**

  - Правила

### Горячие клавиши
- `Ctrl + M` - Таблица Менделеева
- `Ctrl + W` - Старт викторины
- `Ctrl + S` - Статистика
- `Ctrl + E` - Экспорт данных
- `Ctrl + F` - Поиск элементов
